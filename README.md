# Colégio Porto Feliz

Site institucional com navegação responsiva, galeria, Tour 360° e contatos oficiais.

## Publicação

Os arquivos estão organizados para GitHub Pages, com `index.html` e `assets/` na raiz. Em Settings → Pages, selecione Deploy from a branch, a branch main e a pasta /(root).

## Formulário de contato

O envio por e-mail está configurado com a chave pública do formulário Web3Forms. O recebimento deve ser conferido na caixa de entrada do e-mail vinculado à chave. O botão de WhatsApp continua disponível para contato imediato.

## Atualizações

Preserve as fotografias aprovadas, o conteúdo institucional e as preferências de acessibilidade. Os arquivos de publicação do Sites não são necessários para esta hospedagem.
